# Misi Bahasa Melayu Tahun 4 — Dunia Imbuhan

## Kandungan
- `index.html` — sesi PdP interaktif, infografik, pautan carian video YouTube, 20 soalan kuiz, markah bintang, bunyi, suara Bahasa Melayu jika tersedia, keputusan dan eksport keputusan TXT.
- Mesra telefon, tablet dan komputer. Tidak memerlukan pemasangan atau sambungan internet untuk kuiz; YouTube memerlukan internet.

## Cara guna
1. Ekstrak fail ZIP.
2. Buka `index.html` dengan Chrome, Edge, Firefox atau Safari.
3. Masukkan nama murid dan tekan **Mula Misi**.
4. Untuk suara, tekan **Bunyi: ON** dan pastikan peranti membenarkan audio. Ketersediaan suara ms-MY bergantung pada peranti/pelayar.
5. Untuk simpan keputusan, tekan butang **Simpan keputusan (.txt)** pada skrin akhir.

## Terbitkan di GitHub Pages
1. Log masuk ke GitHub dan cipta repositori baharu, contohnya `misi-bahasa-tahun4`.
2. Muat naik `index.html` dan `README.md` ke direktori utama repositori.
3. Buka **Settings → Pages**.
4. Di **Build and deployment**, pilih **Deploy from a branch**; pilih branch `main` dan folder `/(root)`, kemudian **Save**.
5. Selepas penerbitan selesai, URL biasanya berbentuk `https://NAMA-PENGGUNA.github.io/misi-bahasa-tahun4/`.

Saya tidak boleh menerbitkannya ke akaun GitHub pengguna tanpa akses akaun. ZIP ini sedia untuk dimuat naik.

## Reka bentuk PdP
- Tahun: 4
- Tema 4: Kebudayaan, Kesenian dan Estetika
- Unit 11: Indah Seni Sepanjang Zaman
- Fokus: kata berimbuhan awalan dan akhiran
- SK 5.2; SP 5.2.1(i), 5.2.1(ii). Turut menyokong pembacaan bahan bukan sastera (SK 2.3; SP 2.3.2) dan pemurnian ayat (SK 3.3; SP 3.3.2) dalam konteks RPT yang dirujuk.
- Objektif: membezakan imbuhan awalan/akhiran; memilih bentuk berimbuhan mengikut konteks; sasaran sekurang-kurangnya 15/20.
- Nota kurikulum: RPT boleh berbeza mengikut tahun dan sekolah. Sahkan kod serta tajuk unit dengan DSKP/RPT yang sedang digunakan di sekolah.
